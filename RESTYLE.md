# Pose sketch + AI restyle (most reliable)

The **pose-sketches** folder has a Blender sketch of every pose. The sketch gets the pose and props exactly right; the AI only has to add the hair and clothes and restyle it.

## For each pose

1. Open Gemini or ChatGPT.
2. Upload **two pictures**: first the sketch from `pose-sketches`, then your style picture `guides/cafe-chin.png`.
3. Paste the text under that pose below.
4. Save the result into the **guides** folder with the name shown, replacing any older version.

If the AI changes the pose, reply: "Keep the pose exactly like the first picture."
