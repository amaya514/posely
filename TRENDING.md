# Trending poses: influencer, model and celebrity style

18 solo poses: casual, trendy and elegant. Each has two ways to make the picture:

- **A. Text prompt:** paste it into Gemini, ChatGPT or Bing. Use one chat and start each new one with "Same mannequin, same style and background as before."
- **B. Sketch + restyle (more reliable):** upload the sketch from `pose-sketches` first, then your style picture `guides/cafe-chin.png`, and paste the restyle text.

Save each result into the **guides** folder with the file name shown. It appears in Posely under **Trending**.
