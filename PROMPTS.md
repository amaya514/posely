# Posely pose images: prompts for Gemini

Make every image in **one Gemini chat** so the mannequin stays the same. Start with the first prompt, and for each next one say "Same mannequin, same style and background as before." followed by the prompt.

Save each image into the **guides** folder (`Documents\posely\guides`) with the exact file name shown, e.g. `cafe-chin.png` (.jpg or .webp also work). Posely removes the grey background and crops automatically.

If a result has clothes, a floor, a shadow or a busy background, ask Gemini to redo it with "plain flat grey background, no floor, smooth featureless mannequin".
