# Posely pose pictures: prompts

Elegant clay mannequins with long hair worn down, in fitted clothes, dresses and wide-leg trousers. Use these with Gemini, ChatGPT or Bing Image Creator.

Make them in **one chat** so the mannequin stays the same: start with the first prompt, and for each next one say "Same mannequin, same style and background as before." followed by the prompt.

Save each picture into the **guides** folder (`Documents\posely\guides`) with the file name shown, e.g. `cafe-chin.png` (.jpg or .webp also work), replacing any older version. Posely removes the grey background and crops automatically.

If the AI gets the pose wrong, use the pose sketch instead: see RESTYLE.md.
